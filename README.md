# Terre plate — réfutation mondiale

Version de travail publiable — 7 septembre 2026.

## Contenu
- 105 arguments, chacun sur une page dédiée
- 12 expériences mises en avant
- Bibliothèque avec recherche et filtres
- Liste locale « Mes tests »
- 25 langues d’interface (corpus détaillé encore en français)
- Emplacements publicitaires réservés et non activés
- Gestion de consentement préparée
- Pages légales, méthode, sources, à propos, 404
- Responsive mobile/desktop, impression et partage
